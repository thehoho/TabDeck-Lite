# Security policy

## Supported versions

Security fixes are provided for the latest TapDeck Lite 1.0.x release.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a normal issue.
Use [GitHub private vulnerability reporting](https://github.com/thehoho/TabDeck-Lite/security/advisories/new) so the report can be reviewed privately.

For non-sensitive security questions, open a [GitHub issue](https://github.com/thehoho/TabDeck-Lite/issues).

TapDeck Lite intentionally has no Internet permission, analytics, advertising, Accessibility Service, clipboard access, or cloud backup. Reports showing a regression in any of those boundaries are treated as high priority.
