# TapDeck Lite

## One tap. One command.

TapDeck Lite is a compact Android shortcut keyboard for command-driven Discord chats and bots such as OwO. Save up to 40 commands across two pages, tap one key to insert or send it, and reorder each page with immediate drag-and-drop swapping in the app's Keys tab.

It is completely offline, requests no Android permissions, and contains no ads, analytics, or tracking.
